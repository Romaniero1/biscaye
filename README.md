# Biscaye XRD

Клиентское React/TypeScript-приложение для пакетной полуавтоматической обработки XRD-дифрактограмм по зафиксированной методике Biscaye.

## Запуск

```bash
pnpm install
pnpm dev
```

Production-сборка:

```bash
pnpm build
```

Поддерживаются `.dat`, `.txt`, `.xy`, `.uxd`. Имена GL/VS сопоставляются по токену состояния, например `7.IL.GL.dat` / `7.IL.VS.dat` и `1-6.il.gl_004.txt` / `1-6.il.vs_004.txt`. Суффикс после GL/VS сохраняется в идентификаторе образца. Данные и вычисления остаются в браузере.
